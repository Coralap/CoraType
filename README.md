A notepad like text editor build using C and the Windows API.
I used this project to practice C and make a project without downloading libraries

CoraType can:

- Open and save files
- Write and delete in LTR and RTL anywhere
- Move the caret(blinky line) using left and right arrows
- Open files around 5MB
  
CoraType can't:
- Go up or down in the text editor
- Scroll
